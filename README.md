# DRIVECLUB - GT7 Near Chase Camera

The goal of this mod is to reproduce the camera behavior from GT7 as accurately as possible within the current capabilities. 
I spent a long time working on how to adapt the FOV and the distance from the car to the camera so that they match GT7 as closely as possible.

Despite the above, this mod does not fully replicate the camera movement from GT7 due to the specifics of the fixed vanilla scripts used for all cameras in DRIVECLUB.

The camera position coordinate parameters have been changed for every car and bike.



P.S. If you want to return to the vanilla settings of the Chase Camera later, just drag the `data` folder from the `vanilla backup cameras` folder into the game directory.

This mod is compatible with all platforms.

---

### Installation:

Drag only the `data` folder into the game directory, even if there is no `data` folder in your unpacked game folder - the game will still recognize it.
