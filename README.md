# DRIVECLUB - GT7 Near Chase Camera

The goal of this mod is to reproduce the camera behavior from GT7 as accurately as possible within the current capabilities. 
I spent a long time working on how to adapt the FOV and the distance from the car to the camera so that they match GT7 as closely as possible.

The camera position coordinate parameters have been changed for every car and bike.

---

>[!WARNING] 
>Despite the above, this mod only reproduces the camera movement from GT7 by approximately 85%. This is due to the specifics of the fixed vanilla scripts used for all cameras in DRIVECLUB.

---

>[!NOTE]
>This mod is compatible with all platforms.

---

### Installation:

**Drag only the `data` folder into your game directory. Even if the `data` folder doesn't exist there yet, the game will still recognize it.**

P.S. If you want to return to the vanilla settings of the Chase Camera later, just drag the `data` folder from the `vanilla backup chase cameras` folder into the game directory.
